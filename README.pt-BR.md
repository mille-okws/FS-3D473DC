# Foston FS-3D473DC — Engenharia Reversa

> **⚠️ Projeto em andamento**

Exploração e documentação do hardware e software de um **GPS automotivo Foston FS-3D473DC**, com foco em engenharia reversa, sistemas embarcados, Windows CE 6.0 e experimentação.

Este repositório reúne minhas anotações, descobertas, experimentos e documentação enquanto tento entender o que existe dentro desse dispositivo — e, eventualmente, o que mais ele é capaz de fazer.

## 🔍 O que já descobri

* Windows CE 6.0
* Hardware baseado em MStar
* Interfaces UART / pads de teste
* Bateria interna e circuito de carregamento
* Microsoft Office
* Paint
* DOSBox
* Diversos emuladores para Windows CE
* GPS funcionando
* Possibilidade de executar softwares adicionais

## 🧪 Experimentos

Alguns dos experimentos já realizados:

* Exploração do sistema de arquivos do Windows CE
* Identificação de interfaces de hardware
* Testes de comunicação UART
* Execução do DOSBox
* Tentativa de executar Doom
* Execução de UNO
* Investigação de emuladores disponíveis
* Testes de execução de softwares adicionais

## 📚 Documentação

A documentação do projeto pretende abordar:

* Identificação do hardware
* PCB e componentes
* Pinagem e interfaces
* UART e outras interfaces de comunicação
* Alimentação e carregamento
* Windows CE 6.0
* Estrutura do sistema de arquivos
* Softwares e executáveis
* Experimentos de engenharia reversa
* Desenvolvimento e compilação de programas para o dispositivo

## 🚧 Status

O projeto está **em investigação ativa**.

Grande parte das informações ainda está incompleta, é experimental ou precisa ser confirmada. Novas descobertas serão adicionadas conforme os experimentos avançarem.

Informações marcadas como **desconhecidas**, **não confirmadas** ou **experimentais** ainda não foram verificadas.

## 🎯 Objetivo

Entender o dispositivo da forma mais completa possível e documentar o processo para que outras pessoas com hardware semelhante baseado em Windows CE possam reproduzir os experimentos e continuar a investigação.
