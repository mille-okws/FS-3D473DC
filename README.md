# Foston FS-3D473DC — Reverse Engineering

> **⚠️ Work in progress**

Exploring and documenting the hardware and software of a **Foston FS-3D473DC automotive GPS**, with a focus on reverse engineering, embedded systems, Windows CE 6.0, and experimentation.

This repository contains my notes, discoveries, experiments, and documentation while trying to understand what is inside this little device — and, eventually, what else it can do.

## 🔍 What I've found so far

* Windows CE 6.0
* MStar-based hardware
* UART interfaces / test pads
* Internal battery and charging circuitry
* Microsoft Office applications
* Paint
* DOSBox
* Several Windows CE emulators
* Working GPS functionality
* Ability to run additional software

## 🧪 Experiments

Some experiments already performed:

* Exploring the Windows CE filesystem
* Identifying hardware interfaces
* Testing UART communication
* Running DOSBox
* Attempting to run Doom
* Running UNO
* Investigating available emulators
* Exploring software execution on the device

## 📚 Documentation

Documentation will cover:

* Hardware identification
* PCB and components
* Pinouts
* UART and other interfaces
* Power and charging
* Windows CE 6.0
* Filesystem structure
* Software and executables
* Reverse engineering experiments
* Development and compilation for the device

## 🚧 Status

This project is **actively being investigated**.

A lot of the information here is still incomplete, experimental, or waiting to be verified. Findings will be updated as the investigation progresses.

If something is marked as **unknown**, **unconfirmed**, or **experimental**, it means exactly that.

## 🎯 Goal

The goal is to understand this device as completely as possible and document the process so that others with similar Windows CE-based hardware can reproduce the experiments.
